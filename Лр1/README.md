# ЛР №1 «Лінійні перетворення», варіант 16

Система моделювання плоскої деталі з евклідовими, афінними та проєктивними перетвореннями. Усі перетворення реалізовано матрицями 3×3 в однорідних координатах.

- `main.py` — програма (Python, Tkinter)
- `ТР33_Розумович_Л1.docx` — звіт
- `креслення_варіант16.png` — креслення деталі за варіантом

## Запуск

```
python main.py
```

Потрібен лише Python 3 зі стандартною бібліотекою (Tkinter входить до неї).
